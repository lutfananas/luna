            Pilih script untuk diedit, atau buat baru.
          
    
          
    
            
    
            
          
    
          
    
          
    
            
            
          
    
        
    

        
    
          
    Cara pakai
    
          
      
            
    1. Klik tombol simbol (atau tekan /) untuk memilih koin dari semua pair Binance, lalu pilih timeframe.
      2. 
            
    2. Centang script di tab Script untuk menampilkannya di chart. Klik ⚙ untuk ubah input.
      3. 
            
    3. Buat / ubah script di tab Editor dengan sintaks mirip Pine Script v5.
      4. 
            
    4. Script strategy(...) otomatis di-backtest → lihat panel Strategy Tester.
      5. 
            
    5. ⏪ Replay: klik titik di chart, lalu ▶ / → untuk maju bar demi bar. Hasil backtest & paper trading mengikuti posisi replay.
      6. 
          
    
          
    Shortcut
    
          
    / pilih koin · R replay · Spasi play/pause · →/← maju/mundur · B/S/C buy/sell/tutup (saat replay) · Ctrl+Enter simpan script
    
          
    Yang didukung
    
          
      
            
    • Sintaks: x = …, var x = …, x := …, +=, if / else if / else, switch, x = if … / x = switch …, for i = a to b by s, for x in arr, while, break/continue, ternary ?:, and/or/not, histori close[1], tuple [a, b] = …, fungsi f(x) => …, method arr.push(x), tipe float/int/array<float>/…, argumen bernama.
      • 
            
    • Timeframe lain (HTF): timeframe.change("1D"), timeframe.in_seconds(), request.security(sym, "240", high[1]) untuk open/high/low/close/volume (tanpa repaint jika lookahead off).
      • 
            
    • Gambar: box.new/line.new/label.new/table.new + set_*, get_*, delete, .all — mengikuti posisi replay.
      • 
            
    • array.: new_float/int/bool/string/box/line, new<T>, from, push, pop, shift, unshift, get, set, size, remove, insert, includes, indexof, max, min, sum, avg, median, stdev, sort, slice, copy, join, …
      • 
            
    • Deklarasi: indicator(), strategy() (initial_capital, default_qty_type, default_qty_value, commission_type, commission_value, pyramiding, slippage, process_orders_on_close)
      • 
            
    • Input: input.int/float/bool/string/source/color
      • 
            
    • ta.: sma ema rma wma hma vwma swma stdev variance dev rsi macd bb bbw kc atr tr supertrend highest lowest highestbars lowestbars crossover crossunder cross change mom roc cum vwap obv stoch cci mfi dmi barssince valuewhen rising falling pivothigh pivotlow linreg median percentrank wpr sar
      • 
            
    • math.: abs max min round sqrt pow log exp floor ceil sign avg …, na() nz(), str.tostring
      • 
            
    • Plot: plot (line, linebr, stepline, histogram, columns, area, circles), plotshape, plotchar, plotarrow, hline, bgcolor, barcolor, color.new/rgb/from_gradient
      • 
            
    • strategy.: entry, exit (stop, limit, profit, loss), close, close_all, cancel, cancel_all, position_size, position_avg_price, equity, netprofit, openprofit, closedtrades …
      • 
          
    
          
    Belum didukung
    
          
    request.security dengan ekspresi kompleks (dihitung di timeframe chart + peringatan di Log), type/method buatan sendiri, map/matrix, linefill, trailing stop, partial exit, histori variabel lokal di dalam fungsi.
    
          
    Aturan eksekusi backtest
    
          
    Seperti TradingView: order market diisi di open bar berikutnya. Stop/limit dicek di dalam bar (open → high/low terdekat → sisi lain → close). Posisi bersih; entry berlawanan = reversal.
